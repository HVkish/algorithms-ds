# АиСД

Лабораторные по алгоритмам и структурам данных. Python 3.

## task1 — сортировки
- `bubble_sort.py` — пузырьковая сортировка
- `merge_sort.py` — сортировка слиянием
- `quick_sort.py` — быстрая сортировка
- `main.py` — прогоняет все три на одном массиве

## task2 — строки
- `substring_search.py` — все вхождения подстроки (алгоритм КМП)
- `cyclic_shift.py` — минимальный циклический сдвиг

## task3 — стек
- `brackets.py` — минимум удалений до правильной скобочной последовательности
- `nearest_smaller.py` — ближайший меньший справа (монотонный стек)

## task4 — деревья
- `one_child_nodes.py` — вершины ровно с одним ребёнком
- `balanced.py` — проверка сбалансированности дерева

## task5 — графы
- `ege.py` — время доставки из столицы (дейкстра)
- `infrastructure.py` — выбор площадки, центр графа (Флойд—Уоршелл)
